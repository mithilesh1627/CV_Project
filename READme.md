# 🚀 Personal Portfolio Website

Welcome to my personal portfolio built with **Flask** and designed to showcase:

* 👨‍🎓 Academic & Technical Skills
* 📊 Machine Learning & Computer Vision Projects (with live demos & tech tags)
* 📫 Contact form with email integration
* 🌙 Dark theme-first, mobile responsive layout
* 💡 Interactive skill charts and experience highlights

🟢 **Live Site**: [https://mithileshchaurasiya.me](https://mithileshchaurasiya.me)

## 🛠️ Tech Stack

* Python, Flask, Jinja2
* HTML5, CSS3 (animations & dark theme)
* JavaScript (for interactivity & modals)
* Deployed on Render with custom domain & HTTPS
